甚麼是 Virtual Collections 虛擬相簿？

傳統相簿 APP 在分類時，往往會把照片複製或移動到新資料夾，導致手機空間瞬間暴增。
Kufee Gallery 只建立**「持久化引用索引 (Persistent Reference)」**，實現無痛分類。

傳統相簿做法

浪費空間
  • 建立新目錄時重複複製影片與照片，佔用多一倍儲存空間。
  • 無法輕易整合外部 SD 卡、USB 或雲端相片到同一個相簿內。
  • 當移走 SD 卡或斷開雲端時，傳統相簿紀錄容易直接遺失破壞。
Kufee 推薦模式

Kufee Virtual Reference

零額外容量
  • 只儲存指向原檔的輕量 Reference，新增相片到相簿完全不佔用額外 Storage。
  • 彈性離線恢復：拔出 SD 卡時相簿保留紀錄；重新插入時相片自動恢復呈現。
  • 自動智能預設：首次啟動自動產生「所有相片」與「所有影片」動態相簿。
全方位跨平台整合

打破平台邊界，連接你所有的媒體來源

無論相片儲存在 Android 內部檔案系統、SD卡/USB、iOS Photo Library 還是雲端，Kufee 提供統一流暢的瀏覽與管理體驗。

Android Main Storage

支援 Full Filesystem Access 直接瀏覽目錄，自動掃描隱藏資料夾，搭配極速背景 Indexing 機制。

SAF & Other Storages

獨立授權的 SD 卡、USB OTG 或外接硬碟目錄。隨插即用，拔出時自動保護相簿索引不丟失。

iOS Photo Library & Files

內建自訂相簿瀏覽器，無縫整合系統相簿、Recents、iOS Files Document Picker 與外接裝置。

Cloud Storage

支援 Dropbox、Google Drive 多帳號安全連接。將雲端照片與本地照片同存於同一個虛擬相簿中。
